P1 Backups

Política de privacidad

Última actualización: 14 de noviembre de 2026

Esta página describe el tratamiento configurado para P1 Backups, una herramienta privada de copias de seguridad del proyecto P1 utilizada por el propietario de la cuenta de Google autorizada.

1. Contacto de la herramienta

El propietario administra la autorización y las copias. Para consultas sobre este uso de Google Drive o la retirada de acceso, el contacto es recsanenterprise@gmail.com.

2. Acceso a los datos de Google

P1 Backups utiliza rclone y la API de Google Drive con el permiso https://www.googleapis.com/auth/drive.file. Este permiso permite crear, leer, actualizar o eliminar los archivos y carpetas autorizados para la aplicación, incluidos los que ella crea. No concede acceso general al resto de Drive.

La configuración actual trabaja en una carpeta creada mediante esta autorización. Consulta la información necesaria para localizar y comprobar sus archivos, como nombre, identificador, tamaño y contenido cifrado.

La autorización se realiza en las páginas de Google. La contraseña de la cuenta de Google no se introduce en P1 Backups.

3. Finalidad del acceso

El acceso se utiliza para guardar copias cifradas de los datos y la configuración de P1, guardar sus archivos de comprobación y descargar los archivos para verificar la transferencia o realizar un ensayo de recuperación.

La configuración actual de la herramienta no ejecuta borrados automáticos por antigüedad. El propietario controla las operaciones y cualquier modificación de esta configuración.

4. Almacenamiento y protección

Las copias se cifran antes de enviarse a Google Drive y se guardan en la cuenta autorizada. También pueden conservarse copias y archivos de recuperación en los equipos privados del propietario y en el servidor de P1.

Las credenciales de autorización necesarias para renovar el acceso se almacenan en el servidor con permisos de acceso restringidos. No se incluyen en las páginas públicas ni en el repositorio destinado a alojarlas.

El descifrado requiere la clave privada de recuperación, que el propietario conserva fuera del servidor. Las pruebas de recuperación pueden generar archivos descifrados en entornos privados, cuya custodia y eliminación corresponde al propietario.

5. Destinatarios y publicación

Google Drive se utiliza como servicio de almacenamiento de los archivos cifrados. La herramienta no publica las copias ni crea enlaces de acceso público a ellas. El uso descrito consiste en guardar y comprobar copias para la recuperación de P1.

Esta web informativa es independiente de las copias y no contiene formularios de autorización, analítica añadida ni scripts de seguimiento. El alojamiento previsto es GitHub Pages. GitHub aplica sus propias prácticas de tratamiento de datos del servicio, descritas en su declaración de privacidad.

6. Conservación y eliminación

En la configuración actual no hay un plazo automático de eliminación de las copias. Se conservan hasta que el propietario decida retirarlas.

Para eliminar una copia deben revisarse sus ubicaciones en Drive y las copias locales o de recuperación conservadas. Eliminar un archivo de una ubicación no garantiza que se hayan eliminado sus demás copias.

7. Revocar el acceso

El propietario puede retirar la autorización desde las conexiones de su cuenta de Google o contactar con recsanenterprise@gmail.com para revisar la configuración.

La retirada de autorización impide que la herramienta siga usando ese acceso una vez que Google hace efectiva la revocación. No elimina por sí sola los archivos que ya se hayan guardado ni las copias locales.

8. Cambios en esta información

Si cambia el acceso solicitado o el tratamiento de las copias, esta información debe actualizarse antes de utilizar la nueva configuración.
